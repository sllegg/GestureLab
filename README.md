# GestureLab 2.0

Готовое веб-приложение без сборки и установки npm-пакетов.

## Запуск в VS Code
1. Распакуйте ZIP целиком. Откройте папку `GestureLab-2.0` в VS Code: File → Open Folder.
2. Установите расширение **Live Server** от Ritwick Dey.
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.
4. Используйте актуальный Chrome или Edge. Адрес должен начинаться с `http://127.0.0.1` или `http://localhost`, а не `file://`.
5. Нажмите «Включить камеру» и разрешите доступ. Интернет нужен для загрузки MediaPipe, WASM и модели. Шрифт также загружается из Google Fonts; если он недоступен, используется системный.

## Режимы
- **Music:** сначала нажмите «Включить звук» мышью или пальцем. В зоне студии движение по горизонтали выбирает ноты пентатоники, по вертикали меняет фильтр. Есть пауза, громкость и три тембра. При переключении режима или скрытии вкладки звук затихает.
- **Lights:** движение по горизонтали меняет цвет, по вертикали — яркость. Можно использовать обычные регуляторы. Это виртуальная подсветка на экране, не управление физическими лампами.
- **Draw:** удерживайте левую кнопку мыши, касание или pinch и двигайтесь внутри холста. Выберите цвет и толщину, очистите холст или сохраните PNG 1600×1000 с тёмным фоном. Смена размера окна сохраняет рисунок.

## Жесты
Держите одну руку в кадре, при хорошем освещении. Кончик указательного пальца управляет курсором по всему окну. Камера зеркальная: движение вправо ведёт курсор вправо.

Соедините большой и указательный пальцы (pinch) над кнопкой, чтобы нажать её; разъедините перед следующим нажатием. Над ползунком удерживайте pinch и двигайтесь по горизонтали. На холсте pinch рисует; отпускание завершает линию. При потере руки линия прерывается. Системные диалоги выбора цвета и список тембров удобнее использовать мышью/касанием. Для первого разрешения аудио нужен физический клик/касание — виртуальный pinch не является доверенным пользовательским событием браузера.

Камера необязательна: все три режима доступны мышью/касанием сразу. Кнопки также доступны клавиатурой (Tab, Enter); ползунки — стрелками.

## Замена предыдущей версии
1. Остановите старый Live Server, сохраните старую папку как резервную копию.
2. Распакуйте новую версию в отдельную папку. Не смешивайте отдельные файлы со старой версией.
3. Откройте новую папку в VS Code и запустите её `index.html` через Live Server.
4. Закройте старую вкладку. Если браузер показывает старое оформление, нажмите Ctrl+Shift+R.

## Если что-то не работает
- Камера запрещена: разрешите доступ в настройках сайта, затем включите камеру снова.
- Камера занята: закройте видеозвонки и другие приложения, использующие её.
- Ошибка загрузки модели: проверьте интернет и доступ к `cdn.jsdelivr.net` и `storage.googleapis.com`. Мышь продолжает работать независимо от модели.
- Нет звука: нажмите кнопку запуска физическим кликом, проверьте громкость приложения, системы и вкладки. После паузы нажмите запуск снова.
- Не используйте двойной клик по HTML для камеры. На телефоне нужен HTTPS: обычный HTTP с IP компьютера не даёт доступ к камере.

## Структура и зависимости
`index.html` — интерфейс, `styles.css` — адаптивное оформление, `app.js` — звук, свет, холст, камера и жесты.

MediaPipe зафиксирован на **@mediapipe/tasks-vision@0.10.22-rc.20250304**, включая соответствующую папку WASM. Не заменяйте на несуществующую `0.10.22`. Используется Hand Landmarker в режиме VIDEO, одна рука; GPU с повторной попыткой на CPU. Модель: hand_landmarker float16/1.

Документация API: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js

Кадры обрабатываются в браузере. Приложение не записывает и не отправляет видео; внешние запросы нужны для загрузки ресурсов. Это не полностью автономный офлайн-пакет.

## Проверка поставки
Проверены синтаксис JavaScript, ссылки между локальными файлами и логика переключения режимов, рисования, очистки, сохранения и управления аудио с имитацией браузерных API. Проверка реальной камеры/звука и визуальный просмотр в браузере в среде сборки не выполнены: предпросмотр не смог подключиться к локальному серверу. Проверьте их после запуска на вашем устройстве.
